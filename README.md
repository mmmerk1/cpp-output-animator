# 逐行输出动画生成器

一个单文件 HTML 小工具：设定次数与延迟，实时预览逐行输出（`1.re`、`2.re`…），同时显示计时、推算耗时，生成对应 C++ 源码，并可导出视频动画。

## 用法

直接打开 `index.html`，或用浏览器访问线上页面。

1. 设输出遍数（1～5000）或勾「无限」
2. 设单行延迟，单位可选毫秒 / 秒
3. 选计时显示（正计时 / 倒计时）与数值顺序（递增 / 递减）
4. 填后缀文字，默认 `re`，即输出 `1.re`
5. 点「开始运行」：终端逐行刷出，右下角大计时，画布同步渲染
6. 若勾了「运行同时录制视频」，结束后自动生成 WebM，可下载、可就地预览

## 同时产出

- **实况预览**：每行带 `[0.50s]` 形式的时间戳
- **计算**：总行数、单行间隔、首行时刻、末行时刻、总耗时、每秒行数、对应 `usleep` 微秒值
- **C++ 源码**：随参数实时生成，可复制、可下载 `.cpp`
- **视频**：MediaRecorder 抓画布，按真实时间轴，30 fps

## 说明

- 纯前端，无依赖、无网络请求，离线可用
- 生成的 C++ 与页面演示逻辑一致：循环 + `usleep` + `printf`，因为延迟写在循环开头，第一行也要先等一个间隔
- 视频为 WebM；需要 MP4 请自行转码
